    La funzione [xml_response] è definita nel modulo [myutils]:

def xml_response(résultat: dict, status_code: int) -> tuple:
    # risultato: il dizionario da convertire in stringa XML
    xmlString = xmltodict.unparse(résultat)
    # si restituisce la risposta HTTP
    response = make_response(xmlString)

    • riga 3: la funzione [xml_response] riceve come parametri:
      • il dizionario [résultat] da convertire in XML;
      • il codice di stato [status_code] da restituire al client web;
    • riga 5: si utilizza la libreria [xmltodict] per generare la stringa XML;
    • riga 8: si utilizza l'intestazione [Content-Type] per comunicare al client che gli viene inviato XML;

    La funzione [xml_response] deve essere importata nello script [__init__.py]:

    
from .myutils import set_syspath, json_response, decode_flask_session, xml_response

    Successivamente, il modulo [myutils] deve essere incorporato nei moduli a livello di macchina. Ciò avviene in un terminale PyCharm con il comando [pip install .] (nella cartella packages).

    La stringa [<?xml version="1.0" encoding="utf-8"?>] è composta da 38 caratteri. Inoltre, se si esamina il file di log con un editor esadecimale, si nota che dopo questa stringa è presente un carattere di nuova riga \n. Segue poi la risposta <risposta>…</risposta>. La stringa XML che dobbiamo convertire inizia quindi dopo i primi 39 caratteri della stringa XML. Inizia dal carattere n. 39, essendo il primo carattere numerato 0. Questa stringa si ottiene dall’espressione [response.text[39:]].
