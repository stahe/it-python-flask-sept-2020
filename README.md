# Introduzione a Python 3 e al framework Flask

Questo repository contiene il sito web in HTML relativo al corso "Introduzione a Python 3 e al framework Flask attraverso esempi".

🔗 **Visualizza la documentazione online:** [https://stahe.github.io/it-python-flask-sept-2020/](https://stahe.github.io/it-python-flask-sept-2020/)

---

## 📝 Indice

Questo progetto offre un elenco di script Python che coprono vari argomenti:
* I fondamenti del linguaggio.
* Gestione dei database MySQL e PostgreSQL.
* Programmazione di rete TCP/IP (protocolli HTTP, POP3, IMAP, SMTP).
* Programmazione web MVC con il framework Flask.
* Architetture a tre livelli e programmazione basata su interfaccia.

## 🎯 Destinatari

Questa raccolta di esempi è destinata a:
* Sviluppatori che hanno già utilizzato un linguaggio di scripting (Perl, PHP, VBScript).
* Sviluppatori che hanno familiarità con i linguaggi tipizzati (Java, C#) e desiderano esplorare un linguaggio di scripting orientato agli oggetti.

> ⚠️ **Nota:** Questo documento non è adatto a lettori con poca o nessuna esperienza di programmazione.

## 💡 Filosofia

Questo progetto non è né un corso completo né una raccolta di "best practice". Il suo obiettivo è fornire esempi concreti per aiutarti a muovere i primi passi con Python 3 e Flask. Il codice è fornito così com'è e alcuni script potrebbero essere ottimizzati.

Per ottenere il massimo da questo contenuto, è richiesta una **lettura attiva**: devi analizzare il codice, leggere i commenti associati e osservare i risultati dell'esecuzione.
